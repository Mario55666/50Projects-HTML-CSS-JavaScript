📚 Justificación pedagógica (para el docente)

Esta actividad adopta el enfoque DUA-Experiencial: ofrece múltiples formas de implicación (misión narrativa, retos variados, recompensas), representación (piezas visuales, definiciones interactivas, texto y color pedagógico) y acción/expresión (selección, anagrama, arrastre, decisión en simulador, escritura breve).

Se recorre el ciclo experiencial (Kolb): experiencia concreta en la Trivia y el Simulador → observación reflexiva en el feedback → conceptualización en las ventanas de refuerzo (Saussure, Barthes) → experimentación activa en la Ficha y la Sala de Exposición. La secuencia respeta el modelo IUTPC (Inicio, Utilidad, Transformación, Práctica, Cierre) y nunca presenta la definición antes de la experiencia.

El error es productivo: cada fallo abre un panel de cinco componentes (Pausa → Pista → Dato → Contexto → Reintento) sin castigo terminal, garantizando seguridad psicológica y refuerzo positivo constante para la memoria de largo plazo.
