Configuración de la Fuente
Ayuda — ForjaType

1. Selecciona un glifo

Haz clic en cualquier celda del panel izquierdo. El canvas se ajustará automáticamente al tamaño del glifo.

2. Dibuja con la Pluma P

  • Clic en el canvas para colocar el primer punto.
  • Clic para añadir puntos sucesivos.
  • Arrastra mientras haces clic para crear una curva Bézier cuadrática.
  • Clic cerca del punto inicial para cerrar el path.
  • Doble clic para terminar un path abierto.

3. Línea recta L

Clic en el inicio, clic en el fin. Se añade automáticamente al glifo.

4. Bézier cúbica B

Clic inicio → arrastra el primer handle → clic para fijar el segundo handle y el punto final. Dos etapas de control.

5. Editar puntos

Cambia a la herramienta Seleccionar V y arrastra cualquier punto o handle (los puntos naranjas de las curvas).

6. Borrar

Usa el Borrador E y haz clic sobre un punto, o selecciona con V y presiona Delete.

7. Exportar

Cuando termines todos los glifos, presiona el botón dorado Exportar TTF. La fuente incluye automáticamente el glifo .notdef.

Estructura del proyecto JSON

Puedes guardar tu trabajo como JSON y cargarlo posteriormente, o incluso generar el JSON manualmente / desde otro programa para importar vectores.

// Ejemplo mínimo: una letra "A" con un triángulo { "version": "1.0", "fontFamilyName": "MiFuente", "fontStyleName": "Regular", "unitsPerEm": 1000, "ascender": 800, "descender": -200, "xHeight": 500, "capHeight": 700, "glyphs": [ { "id": "_a1b2c3", "char": "A", "name": "A", "unicode": 65, "type": "upper", "advanceWidth": 650, "paths": [ { "id": "_p1", "closed": true, "commands": [ {"type":"M","x":100,"y":0}, {"type":"L","x":200,"y":700}, {"type":"L","x":0,"y":700} ] } ] } ] }

Tipos de comandos

  • M — moveTo: inicia un path. {"type":"M","x":100,"y":0}
  • L — lineTo: línea recta. {"type":"L","x":200,"y":700}
  • Q — quadraticCurveTo: curva cuadrática. {"type":"Q","x":200,"y":700,"cx":150,"cy":350}
  • C — bezierCurveTo: curva cúbica. {"type":"C","x":200,"y":700,"c1x":100,"c1y":350,"c2x":150,"c2y":350}

Importar desde otro programa

Convierte tus SVG paths a este formato JSON. El sistema de coordenadas usa unidades tipográficas (unitsPerEm). El eje Y crece hacia arriba; el baseline está en y = 0.

Para cargar, usa el botón Cargar JSON en el panel derecho.

Atajos de teclado

  • V — Seleccionar
  • P — Pluma
  • L — Línea
  • Q — Bézier cuadrática
  • B — Bézier cúbica
  • E — Borrador
  • G — Mostrar/ocultar grid
  • + / - — Zoom
  • Ctrl+Z — Deshacer
  • Ctrl+Y — Rehacer
  • Delete — Borrar punto seleccionado
  • Esc — Cancelar path en curso
  • Shift+arrastre — Pan / mover canvas
  • Rueda del ratón — Zoom in/out
Importar SVG Path

Pega el código SVG completo (paths, formas, grupos, transforms y arcos) o carga un archivo .svg. Todos los trazos se importarán al glifo seleccionado.
