# Formulario FODA — Fase 2: Rediseño y mejoras

Formulario analítico imprimible para la **Fase 2: Rediseño y mejoras de la propuesta seleccionada (Trabajo en equipo)**, basado en el sistema **FODA** (Fortalezas, Oportunidades, Debilidades, Amenazas).

Desarrollado con la identidad visual del **IDC — Instituto de Educación Superior Público · Diseño & Comunicación**, para la Unidad Didáctica **Proyecto Illustrador** (Diseño Publicitario).

---

## 📄 Contenido del formulario

| Sección | Descripción |
|---------|-------------|
| **Encabezado** | Marca IDC, asignatura, nombre del equipo, docente y fecha de entrega. |
| **01 · Registro del equipo** | Tabla editable con *Nombres*, *Apellidos* y *Correo electrónico institucional* de cada integrante (6 filas). |
| **02–06 · Matriz FODA por producto** | Un análisis FODA 2×2 editable por cada producto, más un campo de *Propuesta de mejora / Rediseño*. |

### Productos analizados
1. Cuento infantil (impreso)
2. Cuento infantil (animado)
3. Infografía (impreso)
4. Juego de mesa (impreso)
5. Juego de mesa (interactivo digital)

Los cuadrantes vienen **pre-cargados** con el contenido del análisis original (editable). El *Juego de mesa interactivo digital* queda en blanco para completar.

## 🚀 Uso

1. Abre `index.html` en cualquier navegador moderno (Chrome, Edge, Firefox).
2. Completa los campos: todos los recuadros son **editables** haciendo clic sobre ellos.
3. Pulsa **🖨 Imprimir / Guardar PDF** y elige *Guardar como PDF* (o imprime directamente). El diseño está optimizado para **A4** con saltos de página limpios y conservación de color.
4. El botón **↺ Limpiar** reinicia todos los campos.

> No requiere instalación, dependencias ni conexión a internet: es un único archivo HTML autónomo.

---

## ✨ Características técnicas

- Archivo único, sin dependencias externas (HTML + CSS + JS en línea).
- Campos editables mediante `contenteditable`, con textos de ayuda (placeholder).
- Modo **claro y oscuro** automático según el sistema, respetando la identidad IDC.
- **Responsive** (se adapta a móvil, tablet y escritorio).
- CSS de impresión dedicado (`@media print`) con formato A4 y color exacto.
- Accesibilidad: foco visible por teclado y respeto a `prefers-reduced-motion`.
